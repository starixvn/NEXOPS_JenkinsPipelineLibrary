<strong>Standard library for Jenkins Pipeline</strong>

<ul>
	<li><strong>restoreNuget()</strong> : Restore nuget packages.</li>
	<li><strong>msBuild(String solutionName)</strong> : Call MsBuild to build the solution.</li>
	<li><strong>xUnitForNetCore()</strong> : Generate C# coverage report for .Net Core projects using xUnit testing framework.</li>
	<li><strong>beginSonarQubeForMsBuild(String key, String name, String additionalParams)</strong> : Prepare SonarQube environment
		<ul>
			<li>additionalParams : configure the additional Params such as: /d:sonar.cs.opencover.reportsPaths="${WORKSPACE}\coverage.xml" /d:sonar.cs.xunit.reportsPaths="${WORKSPACE}\UnitTest.xml" ...
			</li>
		</ul>
	</li>
	<li><strong>endSonarQubeForMsBuild()</strong> : Run SonarQube Analysis</li>
	<li><strong>deployByRocketor(String locationIds, String branchName, String commitHash, String redmineIds, String userToken)</strong> : Call Rocketor to deploy code to environments.
		<ul>
			<li>locationIds: (required) - the location id(s) in Rocketor for deployment. You can input multiple values separated by comma.</li>	
			<li>branchName: (required) - the branch name for deployment. %GIT_BRANCH% will get the build branch so there is no change needed.</li>
			<li>commitHash: (required) - the commit hash for deployment. %GIT_COMMIT% will get the latest build commit hash so there is no change needed.</li>			
			<li>redmineIds: (optional) - the Redmine feature id(s) for SP version change. You can input multiple values separated by comma.</li>
			<li>userToken: it is optional if use Jenkins User Build authorization otherwise required if use User Token authorization.</li>
		</ul>
	</li>
</ul>
