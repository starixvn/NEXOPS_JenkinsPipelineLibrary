<strong>Standard library for Jenkins Pipeline</strong>

<ul>
	<li>restoreNuget() : Restore nuget packages.</li>
	<li>msBuild(String solutionName) : Call MsBuild to build the solution.</li>
	<li>generateCoverageForNetCore() : Generate C# coverage report for .Net Core projects</li>
	<li>beginSonarQubeForMsBuild(String key, String name, String additionalParams) : Prepare SonarQube environment
		<ul>
			<li>additionalParams : configure the additional Params such as: /d:sonar.cs.opencover.reportsPaths="${WORKSPACE}\coverage.xml" /d:sonar.cs.xunit.reportsPaths="${WORKSPACE}\UnitTest.xml" ...
			</li>
		</ul>
	</li>
	<li>endSonarQubeForMsBuild() : Run SonarQube Analysis</li>
</ul>
